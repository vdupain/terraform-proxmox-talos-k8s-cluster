# ai-cluster — Operational Procedures

The `ai-cluster` is a single-node Talos Kubernetes cluster on `pve3` with an RTX 3060
passthrough, serving AI workloads (open-webui + ollama with qwen3.5 models).

**Energy-saving philosophy**: `pve3` is powered off by default. The cluster is started
on demand and shut down cleanly when unused.

Run the scripts from `examples/7-ai-cluster-single-node/` (kubeconfig and talosconfig
are generated by `terraform apply` into `output/`).

## Hardware / network

| Item | Value |
|---|---|
| Node | `pve3` (Proxmox host, powered off by default) |
| pve3 MAC (WoL) | `54:bf:64:6c:b8:53` |
| LAN broadcast | `192.168.10.255` |
| VM `ai-cluster-cp-0` | `192.168.10.203` |
| Cluster endpoint | `192.168.10.203` |
| Cilium LB pool | `192.168.10.230` – `192.168.10.235` |
| Domains | `*.ai.vincentdupain.com` |

## Startup (`ai-cluster-up.sh`)

1. **Wake-on-LAN** — sends a WoL magic packet to `pve3` (UDP broadcast, no Proxmox API).
2. **Wait for boot** — polls SSH port 22 on `192.168.10.203` (default timeout 300s).
3. **Verify Ready** — `kubectl wait --for=condition=Ready node --all`.

```bash
./ai-cluster-up.sh
```

Idempotent: safe to re-run.

## Shutdown (`ai-cluster-down.sh`)

1. **Cordon** — stop new workloads on the node.
2. **Drain** — evict running workloads safely (protects PVs and etcd).
3. **Talos shutdown** — ordered halt, powers off the VM.

```bash
./ai-cluster-down.sh
```

Idempotent: safe to re-run.

## Models

| Model | Size | Use |
|---|---|---|
| `qwen3.5:9b` | ≈ 6 GB | Main model |
| `qwen3.5:0.8b` | ≈ 1 GB | Smoke tests |

Models live on the ZFS pool (`zfspv-pool` on the user disk, PV 15Gi).
To add more models, grow `user_disk_size` in `main.tf` (`autoexpand=on` picks it up).

## Troubleshooting

- **`ollama list` empty after startup** — check the open-webui HelmRelease has the
  `ollama.ollama.models` structure (double nesting, subchart v1.65.0) so the postStart
  hook pulls models.
- **GPU not detected** — check `kubectl get nodes -o json | jq '.items[0].status.capacity'`
  for `nvidia.com/gpu`; verify the PCI path `0000:b3:00.0` and `local-zfs` datastore in
  `main.tf`.
